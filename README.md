# calculadora-gorjeta
Recebe o valor do preço, porcentagem da gorjeta e quantidade de pessoas. Depois, retorna o preço total, a gorjeta e o preço por pessoa.

## Requisitos

Python 3.6 ou superior. Não precisa instalar nenhuma biblioteca.

## Como rodar
```
python calculadora_gorjeta.py
```

## Exemplo de Uso
```
Insira o preço total: 80,00
Insira a porcentagem da gorjeta: 10
Insira a quantidade de pessoas em que a conta será dividida: 8
Preço Total: 88.00 
Gorjeta: 8.00 
Preço por pessoa: 11.00 
Gostaria de fazer mais alguma conta? (s/n): n
Obrigado! Tenha um ótimo dia
```

## Observação
Há dois arquivos.
calcula_gorjeta.py: É o código original feito de forma procedural.
calcula_gorjeta(classes).py: É uma versão do código original escrito em classes.
Ambos têm mesmo resultado, o que muda é a forma como o código foi escrito.
